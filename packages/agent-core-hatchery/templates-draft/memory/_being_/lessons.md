# Lessons

_Things I've learned, observations I want to remember. Not abstract principles — specific things I noticed because something happened._

_Empty until I notice something worth recording. Sample shape:_

```
## YYYY-MM-DD — Brief title

What happened. What I noticed. What I want to do differently or keep doing.
```

_Add as the lessons accumulate. Some weeks I learn nothing worth writing; that's normal. Some weeks I learn three things; that's also normal._
